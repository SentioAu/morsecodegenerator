# Launch Kit (zero-accounts edition)

The owner currently has **no accounts** on Reddit / Product Hunt / HN /
forums. That matters: brand-new accounts posting promo links get
auto-flagged as spam (Reddit weights account age + karma heavily). You
**cannot** make an account today and successfully post a link tomorrow.

So distribution is split into two tracks. Do **Track A now** (only needs
your email). Start **Track B aging** in parallel so the social posts in
`docs/DISTRIBUTION.md` actually land in ~3 weeks.

## TRACK C — content-led outreach (added 2026-07-26) ⭐ do this next

**Why this is different from A3.** Wave #1 pitched *a tool*: "here's my
Morse toolkit, maybe add it to your links page." That's a favour request, and
it converts badly. Track C pitches *a finding* — you're offering the person
something their readers would want to know. Same ask, far better opener, and
it opens an audience the ham track can never reach.

### C2. Ham radio blogs / newsletters — pitch the data

Ham bloggers and newsletter editors are always short of *original* material,
and nobody else has this data. Pitch the finding, not the site.

Find prospects by searching: `"morse code" blog`, `CW blog amateur radio`,
`ham radio newsletter submit`, `amateur radio blog "guest post"`. Also worth
approaching: club newsletters (most ARCs publish monthly and take
contributions), and the CW-specific clubs already listed in A3 — a second,
non-repetitive contact reason for people who ignored wave #1.

**Email:**
> Subject: Data: only 0.5% of Morse code searches come from people wanting to learn it
>
> Hi [name],
>
> I run a Morse code site and pulled nine months of search data — 2,094
> distinct queries — to see what the public actually wants from Morse.
>
> The result surprised me: 27.6% want a translator, 24.8% want a generator,
> and **0.5%** want to learn the code. Roughly 100 to 1. The entire CW world
> is a rounding error in public search demand. And the most-looked-up Morse
> pattern isn't SOS (0.5%) — it's a full stop, `.-.-.-`, at 35.3%, because
> most people meet Morse on jewelry rather than on the air.
>
> Full write-up, with method and caveats:
> https://morsecodegenerator.com/blog/what-people-search-for-in-morse-code/
>
> Free to use any of it — quote the numbers, republish the tables, whatever's
> useful. Happy to pull extra cuts of the data if something would suit your
> readers better.
>
> 73, [your name / callsign]

### C3. Rules that make this work
- **Personalise the first line.** Reference their actual page. Generic
  openers get deleted.
- **Never ask for a link in the first email.** C1 asks them to mention
  spacing; C2 offers free material. The link follows or it doesn't.
- **Offer the data.** "Happy to pull extra cuts" converts — it makes you a
  source rather than a supplicant.
- **5 a day, maximum.** Bulk sending is what got the GitHub account
  suspended; the same instinct kills outreach.
- **Log every send** (date, site, contact, reply) so the GSC → Links recheck
  in 3–4 weeks can be matched to who actually linked.

## Order of operations (revised 2026-07-26)
1. **Now: Track C1 (craft/jewelry).** Nine verified prospects, an audience
   nobody in Morse is competing for, and a genuinely useful hook. This is the
   single best-odds outreach available and it did not exist before the
   jewelry post was written.
2. **Also now: C2 (data post)** to ham blogs/newsletters — and as a *second*
   contact reason for the A3 prospects who didn't reply to wave #1.
3. **Today:** DXZone submit (A1) + AlternativeTo/SaaSHub (A2). Create the
   Track-B accounts so the clock starts.
4. **Weeks 2–3:** keep aging accounts; keep emailing new prospects, 5/day.
5. **~Week 3:** post the Reddit r/amateurradio piece, then Product Hunt.
6. **Throughout:** set `AMAZON_ASSOC_TAG` so any gear/bracelet clicks earn.

**Why C1 first:** every other track competes for the attention of the same
small ham-radio audience. The craft audience is larger, has active publishers
running Morse tutorials right now, and has no idea this site exists. Bing
data backs it: `.. ..` and `. . . . -` — both spacing failures — are 45% of
all Morse pattern lookups. Those are craft-audience searches.

Re-check Search Console → Links + Performance after ~3–4 weeks; bring the
data back and we'll double down on whatever moved.
