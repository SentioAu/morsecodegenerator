# ⚠️ DO NOT "de-duplicate" the Disallow lines below.
# A crawler obeys exactly ONE group — the most specific one matching its
# name — and ignores every other group, including "User-agent: *". So a
# named group containing only "Allow: /" silently exempts that crawler from
# every rule in the "*" group. That is a real bug we shipped: Googlebot and
# Bingbot were never subject to the ?q= disallows, and Google crawled ~220
# /translate/?q=… URLs as a result (GSC: 144 "Alternate page with proper
# canonical tag" + ~75 "Crawled - currently not indexed").
# Every named group must therefore repeat the crawl rules verbatim.

User-agent: *
Allow: /
Disallow: /translate/?
Disallow: /*?q=
Disallow: /*?lang=
Disallow: /*?text=
